User Feedback
=============

**Endpoint:** `/feedback`

**Method:** `POST`

**Description:**

Submit user feedback after completing a lesson or quiz.

**Request Body Example:**

.. code-block:: json

    {
        "user_id": 42,
        "lesson_id": 1,
        "feedback": "This lesson was very informative and well-structured."
    }

**Response Example:**

.. code-block:: json

    {
        "status": "success",
        "message": "Feedback submitted successfully."
    }
